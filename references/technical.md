# 技术面信号规则（源自 TradingAssistantPy 实战规则库）

> 实际计算请运行 `scripts/technical_engine.py`（本文件是规则说明，不是手算依据）。
> 用法：`python scripts/technical_engine.py kline.json`，kline.json 为 `[["日期",开,收,高,低,量], ...]`。

数据要求：日K ≥25 根（否则判"数据不足"）。核心变量：`量比=当日量/20日均量`、`价格位置=收盘价在近21根高低区间的分位(0–1)`、`实体占比=实体/振幅`。

## 一、MA 均线状态（趋势跟踪）
- 周期：默认 MA(5/13/30/55)，可配。
- **突破/跌破**：价格上穿 MA → BREAK_UP（多头信号）；下穿 → BREAK_DOWN（空头信号）。只算"状态翻转"那一次，不重复报。
- **右侧趋势（重要）**：`收盘价 > MA5 > MA20` 视为"确认上升趋势，可择机买入"；反之 `收盘价 < MA20` 视为趋势走弱。
- **破位扫描**：现价低于 MA(5/13/30/55) 中任一，标记"破位"，批量提示减仓风险。

## 二、量价买卖信号（10 种固定形态）

### 卖出信号（5 种）
| 形态 | 触发条件（全部满足） |
|---|---|
| 高位放量滞涨 | 价格位置>75% + 量比>1.4 + 实体占比<40% + 当日涨跌幅<±1.5% |
| 天量天价 | 量比>3.0 + 价格位置>80% |
| 放量大跌 | 量比>2.0 + 跌幅>2% + 收阴 |
| 量价背离 | 近5日价升量缩（首日量>末日量）+ 价格位置>60% |
| 缩量滞涨 | 连续缩量 + 高位横盘 + 实体<50% + 跌幅不超2% |

### 买入信号（5 种）
| 形态 | 触发条件（全部满足） |
|---|---|
| 缩量下跌 | 连跌3日且量能递减 + 量比<0.7 |
| 地量地价 | 量比<0.4 + 价格位置<35% |
| 底部放量 | 量比>1.8 + 价格位置<40% + 跌幅>2%但未续跌 |
| 缩量回调 | 上升趋势中回调(−0.5%~−3%) + 缩量(量比<0.7) |
| 缩量止跌 | 低位缩量(量比<0.5) + 价格位置<40% + 实体<45% + 几乎不动 |

解读口径：**地量/缩量见底 + 低位放量吸筹 = 买；高位放量滞涨/天量 = 卖**。信号仅作触发器，须与基本面交叉确认。

## 三、风险评分（0–100，累加封顶）
| 因子 | 加分 | 触发条件 |
|---|---|---|
| 跌破 MA20 | +20 | 收盘 < MA20 |
| 跌破 MA5 | +10 | 收盘 < MA5（且高于 MA20） |
| RSI 超买 | +20 | RSI(14) > 75 |
| RSI 超卖 | −10 | RSI(14) < 25 |
| 量能异常 | +15 | 当日量 > 20日均量×2 |
| 大跌 | +20 / +10 | 当日跌幅 <−3% / <−1% |
| MACD 空头 | +15 | EMA12 − EMA26 < 0 |

分级：≥60 **HIGH（高风险）**；≥30 **MEDIUM**；其余 **LOW**。

## 四、短窗口异动（盘中毛刺）
- 默认规则：3 分钟内涨跌 ≥3% **或** 5 分钟内 ≥5%（OR/AND 可配）。
- 捕捉急拉/急杀，与均线、量价信号互补（更高频、更短视）。

## 五、技术面使用纪律（含 2026-08 三轮回测修正）

### 实测可靠性注记（三轮回测 · 五组样本：持仓18 / 关注63 / 药30 / 红9 / 导22，各 320 日，2025-04~2026-08）
**全景表（fwd10 均值，%）：**

| 组 | 基准 | 底部放量 | 缩量止跌 | 缩量回调 | 缩量下跌 | 地量地价 | SELL 信号 |
|---|---|---|---|---|---|---|---|
| 导(半导体/AI主线) | **+3.21** | **+5.81** | **+4.44** | +2.12 | +0.14 | +2.55 | 全面反指(+3~4%) |
| 持仓(强势成长) | +1.28 | +1.58 | +1.66 | −0.16 | −1.03 | −0.06 | 反指 |
| 关注(广覆盖) | +0.57 | −0.41 | −0.60 | +0.93 | +0.60 | +0.20 | 价<MA20 时有效(−1.41%) |
| 红(红利/防御) | +0.44 | −2.19 | +0.46 | +0.91 | +0.16 | +1.03 | 高位滞涨/放量大跌有效 |
| 药(创新药/弱势) | +0.41 | −0.07 | −0.58 | −0.88 | +0.82 | −0.75 | 缩量滞涨有效(−1.98%) |

**跨轮稳健结论：**
1. **趋势强度决定信号有效性**：主升主线（导组）里所有 BUY 放大有效、所有 SELL 反指失效；弱势组（药/关注）BUY 基本无效、SELL 在价格<MA20 时有效。**"低位反转 vs 右侧延续哪个灵"完全由个股趋势状态决定。**
2. **BUY 策略名不可跨组分级**：底部放量/缩量止跌在强趋势组最灵（+5.8%/+4.4%），在弱势组反而最差（−0.1%/−0.6%）；缩量回调反之。
3. **SELL 信号只在弱势/防御品种且价格<MA20 时有效**；强趋势主线中 SELL 全部反指（主升浪洗盘），不应因高位技术信号卖出。
4. **风险分层 LOW>MEDIUM>HIGH 在 5/6 口径成立**（3 轮中仅 1 口径矛盾，反例样本 n=2 无意义）→ LOW 分组买入相对更好，**HIGH(≥60) 分回避买入**跨轮有效。
5. 样本量注意：红组仅 9 只、HIGH 分层样本常 <5，属小样本，结论权重降低。

### 修正后的使用规则（覆盖第二节原始条件；趋势状态三分法）
1. **第一判断=趋势状态**（`收盘>MA5>MA20`=右侧强趋势 / 夹在中间=中性 / `收盘<MA20`=走弱）：
   - **右侧强趋势（含主线品种）**：低位反转类 BUY（底部放量/缩量止跌）放大有效 → 回调低吸；**SELL 信号反指，不因高位滞涨/量价背离卖出**，仅跌破 MA20 才减仓。
   - **中性**：BUY 信号弱化使用，等待方向；SELL 信号只观察。
   - **走弱**：**不因"跌得够多"抄底**（低位放量/止跌=接刀）；SELL 信号（尤其缩量滞涨、放量大跌）在价格<MA20 时有效 → 作为减仓/止盈触发。
2. **BUY 信号：只做形态描述，不作置信分级**——置信度由"趋势状态 + 非 HIGH 风险分"决定，不按策略名。
3. **SELL 定位**：风控/止盈工具，非"预测顶部"工具。有效条件 = 价格<MA20 且非强趋势主线。
4. **风险分**：LOW/MEDIUM 分下可考虑买入，**HIGH(≥60) 分回避买入**（跨轮有效）；风险分不单独作为 BUY 择时依据。
5. **共振优先**：右侧强趋势 + 低位反转类 BUY + 非 HIGH 风险分 → 可积极建仓；弱市/走弱状态下信号仅作回避参考。
6. **环境声明**：四轮均为上行市；强趋势主线（如半导体/AI）中信号"放大"部分来自主升浪 beta。震荡/熊市需用 `scripts/backtest.py` + 定向验证重跑。技术信号是放大器，选股（基本面）才是发生器。
