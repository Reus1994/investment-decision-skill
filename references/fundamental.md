# 基本面框架（守拙君五步法 + 李录审美）

> **出处声明**：本文件第一~三节（核心哲学、公司分类、五步流程、估值公式、安全边际、卖出条件）即用户自定「守拙君」价值投资框架全文，逐条收录；第四节李录六维为其补充的审美检查。分析输出时按 Step6 以【守拙君金句】引述原则。

> 估值公式请运行 `scripts/valuation.py` 计算（本文件是规则说明）。
> 用法：`python scripts/valuation.py params.json`，params.json 填 PE/PB/ROE/增速/股息率/折现率/市值/净现金/主营利润。

## 一、公司分类标准（先分类，再估值）

| 类型 | 特征 | 估值方法 | 仓位上限 | 买入标准 |
|---|---|---|---|---|
| **进攻组合** | 高波动高成长、ROE>15%、商业模式清晰、利润路径可预测 | PB+ROE、PEG、市值-投资价值 | 单只 15–40%（上限 25%） | 5年视角年化>15%，估值处于历史30%分位以下 |
| **防守组合** | 低增长高股息、业绩稳定、行业格局固化 | PE+股息率、永续增速折现 | 单只 10–25%（上限 15%） | 股息率>4%，PE<15（消费）或PE<6（银行），年化>10% |
| **替补组合** | 商业模式未完全成型、长期高估、偶尔低估 | 能力圈+安全边际，50%价值+50%风险投资 | 单只 2–8% | 价格跌到历史低位区间，且对长期逻辑有深刻理解 |
| **放弃** | 任一淘汰项直接放弃 | — | — | 行业衰退 / 管理层乱跨界 / 护城河瓦解 / 完全看不懂 |

## 二、五步分析流程

### 步骤1：定性分析（商业模式检查）
- 一句话说清主营业务
- 行业竞争格局：寡头垄断 / 双寡头 / 红海竞争
- 护城河：品牌 / 成本 / 网络效应 / 牌照 / 资源
- 管理层：是否专注主业？资本配置能力？
- 长期需求：5–10 年后行业还在吗？
- 淘汰项：行业衰退期 / 管理层频繁跨界乱投资 / 护城河正在瓦解 / 看不懂

### 步骤2：定量分析（财务体检）
| 指标 | 标准 | 淘汰项 |
|---|---|---|
| ROE | 连续5年 >15%（低于10%直接排除，强周期底部除外） | ROE 连续3年下滑无拐点 |
| 毛利率 | 稳定或缓慢提升 | — |
| 经营现金流/净利润 | >80% | 经营现金流长期远低于净利润 |
| 有息负债率 | <60%（高负债周期股更严） | >70% 且行业下行 |
| 资本开支/净利润 | 轻资产<30%，重资产看 ROIC | — |
| 分红率 | 防守型 >50% | — |

### 步骤3：估值计算（按类型选公式）
- **类型A（消费/金融/医药）**：合理PE = 1/(折现率 − 永续增速)。例：10% 折现、5% 永续 → 合理 PE=20。当前PE < 合理PE×80% → 低估买；> 合理PE×120% → 高估卖。防守型要求 PE<15 且股息率>4%。
- **类型B（资源/周期）**：预期收益率 ≈ ROE/PB。PB<1.2 且 ROE>15% → 低估。用 10 年长期价格中枢（油价>60美元均值、铜铝 5–10 年中位）测算利润，不用当年价格。
- **类型C（高成长）**：PEG = PE/利润增速(g)。PEG<1 低估买；1–1.5 合理持有；>2 高估卖。
- **类型D（互联网）**：剩余市值 = 市值 − 股权投资价值 − 净现金；剩余PE = 剩余市值/主营业务利润。剩余PE<15 低估，>30 高估。
- **类型E（周期成长）**：周期低点 PE<15 且 PB<3；周期高点看 PB 不看 PE。资源储量/产量比高、并购能力强为加分。

### 步骤4：安全边际检验（买入前全部满足）
- [ ] 当前估值处于历史 30% 分位以下，或 PEG<1，或 PB<1.2
- [ ] 未来3年利润零增长时，当前估值收益率仍 >8%
- [ ] 单只仓位 ≤ 总资产 25%（进攻）/ 15%（防守）
- [ ] 能看懂公司未来 5 年的利润来源
- [ ] 防守型公司股息率 >4%
- [ ] 股价再跌 30% 也睡得着觉

### 步骤5：买入节奏与仓位
- 首次建仓只用计划仓位的 30–50%
- 每跌 10–15% 加仓一次
- 短期涨 20%+ 停止加仓，等回调
- 进攻单只上限 25%，防守单只上限 15%
- 保持 5–15% 现金应对极端下跌

## 三、卖出条件（任一满足即卖）
1. 5年视角利润增长驱动的内在收益不足 10%
2. 估值涨到历史 70% 分位以上，且无更高收益理由
3. 核心买入逻辑被证伪（护城河瓦解、管理层变质、行业逻辑变化）
4. 发现预期收益率高 35% 以上的替代标的
5. 基本面恶化但股价未反映（业绩连续 2 季度超预期下滑）

## 四、李录（巴菲特/芒格衣钵）审美检查 —— 六维加分项
1. **业务质量/护城河**：高 ROIC、定价权、忌资本黑洞（资本开支吞噬自由现金流）。
2. **管理层德才兼备**：德先于才——诚实、专注主业、资本配置理性（分红/回购/再投资纪律）。
3. **长坡厚雪 + 现代化契合**：行业长期成长，且契合"现代化"（效率提升、渗透率、全球化）进程。
4. **价格/安全边际**：好公司也要好价格。
5. **能力圈**：看不懂的不碰。
6. **集中 + 耐心**：能力圈内重仓少数优质公司，长期持有，避免为分散而分散。

## 五、实盘化检查（决策前最后一遍）
- 结论必须是 BUY / SELL / HOLD 之一，不允许"模棱两可"
- 每个数字（ROE/PE/PB/增速/股息率/分位）都来自数据，不拍脑袋
- 给"理想买点区间"而不是"现在就能买"
- 明确"什么情况会触发卖出"，写进备忘录
